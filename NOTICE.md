# Atribuciones

Elaboración propia con datos extraídos del sitio web del **INE**, www.ine.es. Se preservan las fechas, los ámbitos y las unidades de las fuentes. [Condiciones de reutilización](https://www.ine.es/dyngs/AYU/es/index.htm?cid=125). El INE no respalda este proyecto ni sus transformaciones. Los CSV derivados no se ofrecen como una publicación oficial del INE.

Tablas originales 2074, 2066, 10823, 10839, 24746 y 39364: URLs, fechas y huellas en `data/source-manifest.json`. La autorización del código MIT no reemplaza las condiciones de los datos de origen.

Mapa provincial: subconjunto de Andalucía de [spain-provinces.geojson](https://github.com/codeforgermany/click_that_hood/blob/main/public/data/spain-provinces.geojson), proyecto click_that_hood. Su [metadata original](https://github.com/codeforgermany/click_that_hood/blob/main/public/data/spain-provinces.metadata.json) atribuye los límites a CartoDB Common Data. Se conserva la licencia MIT del repositorio en `docs/map-source-license.txt`; no se atribuye una licencia CC0 no indicada en esos metadatos.
